# 앱에서 올릴 릴스

봇이 만든 릴스 사진·영상입니다. **음악은 비어 있습니다** — 인스타 앱에서 트렌드 음원을 골라 올려 주세요.

1. 「사진 받기」·「영상 받기」 를 눌러 휴대폰에 저장합니다.
2. 인스타 앱 → ＋ → 릴스 → 저장한 사진·영상 → 「오디오」 에서 음원을 고릅니다.
3. 아래 본문을 복사해 붙여 넣고 올립니다. 본문을 그대로 두면 다음 릴스를 둘 때 봇이 올라간 것을 알아보고 「인스타에 올림」 표시를 붙입니다.
4. 「고정 댓글」 을 카드뉴스와 릴스에 댓글로 붙여 넣고 길게 눌러 고정합니다.

사진·영상은 올렸든 안 올렸든 3일이 지나면 지워집니다.

```text

```
